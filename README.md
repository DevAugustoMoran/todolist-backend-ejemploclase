# Backend - Sistema de Gestión (API Node.js)

Este es el núcleo de servicios (Backend) del proyecto, desarrollado sobre **Node.js** utilizando el framework **Express**. La base de la estructura fue generada con `express-generator` y optimizada para un entorno de desarrollo.

## Requisitos Previos

Asegúrate de contar con las siguientes herramientas instaladas:

*   **Node.js**: v24.13.1
*   **npm**: Gestor de paquetes.

## Instalación y Configuración

Sigue estos pasos para preparar el entorno local:

1.  **Instalación de dependencias base:**
    Abre una terminal en la raíz del proyecto y ejecuta:
    ```bash
    npm install


## Instrucciones de Ejecución
